# DeLima House — Customer website (V14)

Static informational website. No customer cart or checkout.

## GitHub Pages deployment

1. Create or use a public repository, e.g. `website-indianocean/DeLima-House`.
2. Upload **all files in this directory** to the root of the repository's `main` branch (not the ZIP file itself).
3. In GitHub, open Settings → Pages. Under Build and deployment, select Deploy from a branch, `main`, `/(root)`, then Save.
4. The website address will be shown by GitHub Pages once deployment succeeds.

All files are in the repository root: no subdirectories required. The customer content is not synchronized with the local admin dashboard.

Note: This V14 source deliberately includes a `noindex` meta tag from the prototype. Remove it before launching to allow search-engine indexing.
